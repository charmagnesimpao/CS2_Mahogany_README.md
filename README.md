# Distance: Calculate and Discover

## Description

This program allows the user to quickly calculate the distance between two points inputted at the very start. ( x1 , y1 ) and ( x2 , y2 )

## How to Run

1. Open the program.
2. Run the program.
3. Enter the required values. ( x1 , x2 , y1, and y2 )
4. Make sure the inputted values are valid integers.
5. Wait for the program to calculate for you.
6. Retrieve the calculated distance.

## Input Needed

- Integers
- Non Decimal Numbers
- Non Symbols

## Sample Output

Enter your x2:7

Enter your y1:6

Enter your y2:9
